## 🚀 Como Executar

O projeto utiliza **npm workspaces**, permitindo execução a partir da raiz:

```bash
# Instalar dependências
npm install

# Iniciar servidor local
npm run dev

# Gerar build de produção
npm run build
```

## ✨ Recursos Implementados a partir do Google Maps

1. **Mapa Interativo Incorporado:** Iframe centrado na Av. Pratagy 270 com controles de zoom e visualização clara do local.
2. **Botões de Ação Direta no Google Maps:**
   - **"Como Chegar (Rotas)"**: Gera a rota ponto a ponto no Google Maps até a porta da academia.
   - **"Abrir no Google Maps"**: Abre o link oficial compartilhado da unidade.
   - **"Copiar Endereço"**: Copia o endereço completo formatado com 1 clique.
3. **Seção de Avaliações Conectada ao Google:**
   - Destaque oficial de perfil verificado do Google Meu Negócio.
   - Botão **"Ver avaliações no Google"** e **"Deixe sua avaliação"** direcionando para o link fornecido.
   - Estrutura íntegra e transparente: sem criação de depoimentos fictícios.
4. **SEO Local & Schema.org:**
   - Inclusão de dados estruturados `ExerciseGym` no `index.html` para indexação rica no Google.
5. **Galeria Segura:**
   - Fotos e vídeo originais com autorização mantidos no Espaço Kids.
   - Slots e layout preparados para novas fotografias de alta resolução da musculação e salas coletivas.
6. **Preservação Comercial Estrita:**
   - Nenhum preço de plano foi alterado.
   - Nenhuma informação de outra unidade (como a Unidade 02) foi misturada.
